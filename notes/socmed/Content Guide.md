# Le Wagon Bali Content Guide

> Absolute source of truth: [[Le_Wagon-Branding_Guidelines-Feb2024.pdf|Le Wagon Brand Guidelines — Feb 2024]]. This note applies the global guidelines to Bali social media content. If the two conflict, the PDF wins.

## 1. Brand Foundation

### Logo & Symbol
- Use only the updated Le Wagon logo: squared shape, three-window minibus symbol.
- Do not use the old circular logo, old four-window minibus, or old red `#FD1015`.
- Minimum sizes: combination mark and symbol both 30px.
- Never place the logo or symbol on a red background; keep the minibus white.
- Over photos, use the white wordmark in a neutral area. Add a 20–30% black overlay if readability suffers.

### Core Colours
- **Le Wagon Red:** `#E60F05` — logo symbol, check marks, occasional CTA on Dark Purple.
- **Black:** `#1B1717` — text on light backgrounds.
- **White:** `#FFFFFF` — backgrounds, light text.

### Social / Ad Colours
- Use **Purple `#5315B8`** as the main background for social and paid ads. Do **not** use **Blue Purple `#4D04C4`** as a background.
- Approved backgrounds: Dark Purple `#371373`, Purple `#5315B8`, Purple 05 `#F5F2FB`, Cream `#FCF3EE`, White.
- **Tonic Purple `#670BFF`**: primary filled and outlined buttons on light backgrounds.
- **Orange Peel `#FF9D0B`**: pill accent labels only. **Orange Peel 20 `#FFECD0`**: pill-label background only.

### Typography
- **Headings:** Circular (Bold 700 / Medium 500).
- **Body, labels, buttons:** Inter (Bold 700 / Regular 400).
- Never use Inter for headings or Circular for body copy.
- Never use italics for either typeface.

### Imagery & Graphic Language
- Use real Le Wagon students, teachers, drivers, and alumni from the internal image bank.
- Warm, positive, diverse — show the energy and life change, not stock people.
- Rounded corners: images 16–24px, CTAs 8px, cards 24px.
- No borders, strokes, or drop shadows on images.
- No emojis except in Demo Day visuals.

## 2. Audience & Messaging

### Core Demographic Profile
- **Age:** 25–40, sweet spot 28–33
- **Life stage:** Mid-career professional with 3–10 years of work experience
- **Education:** University-educated, not necessarily technical
- **Language:** English-speaking, international mindset
- **Origin:** High-income countries (US, UK, Australia, Western Europe) with savings or remote income
- **Motivation:** Career change, remote upskilling, or building an independent tech career
- **Values:** Lifestyle, freedom, community, travel, meaningful work

### Psychographic Segments
- **Career Pivoter:** wants a structured path into tech without a CS degree; values outcomes and alumni networks.
- **Remote Upskiller:** tech-adjacent, wants AI/data skills while keeping income; values flexibility and mobility.
- **Builder / Freelancer:** wants ownership, location independence, and a network; values community and hands-on projects.

### Content Filters
Before publishing any post, check:
1. Would a 30-year-old mid-career professional in London, Sydney, or New York stop scrolling for this?
2. Does it assume they have savings, work experience, and a desire to change trajectory?
3. Does it sound like it could only happen in Bali, or could it be any Le Wagon campus? (If it could be any campus, add a Bali-specific layer.)
4. Does the CTA match their motivation: new job, better remote job, or independent work?

### Voice & Tone
- Direct, confident, practical.
- Lifestyle-aspirational but not tourist-y.
- Community-focused, not corporate.
- Evidence-based: alumni stories, outcomes, project examples.
- Avoid generic “learn to code” language. Speak to transformation, not just education.

## 3. Social Media Specs

| Format | Dimensions | Margins |
|---|---|---|
| Paid ads | 1080×1080px (1:1) | 60px |
| Organic posts | 1080×1350px (4:5) | 60px |
| Stories | 1080×1920px (9:16) | Top & Bottom 250px, Left & Right 60px |
| Eventbrite / Meetup | 1186×666px (16:9) | 72px |

## 4. Brand Guardrails

- Never use the old logo, old red, or old four-window minibus.
- Never use black or red as background colours.
- Never use Blue Purple `#4D04C4` as a background; replace it with Purple `#5315B8`.
- Never use Le Wagon Red as a font colour.
- Never use red or orange as a highlight colour, and never highlight more than two words.
- Never add strokes, borders, or drop shadows to images.
- Never use alternative fonts or colours outside the approved palette.
- Never use emojis except in Demo Day visuals.
- Never use gradient backgrounds outside the predefined social/paid-ad templates.
- Avoid mixing too many purple variants in one asset.

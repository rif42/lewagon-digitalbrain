**What does each event status mean?**
Use these statuses to clearly track where each event stands in the planning process and communicate effectively with your team.
**Idea: **This is a **placeholder** for an event you’d like to host. You’re still exploring the idea — it’s a way to signal interest and reserve the date while aligning with your team.
**Upcoming: **You’ve aligned with key stakeholders (e.g. S&A for an info session), and the event is confirmed.
You’ve likely already added it to the www or are preparing to do so. Logistics may still need to be finalized.
**In Progress: **The event is actively being prepared. You’re handling logistics — confirming speakers, ordering goodies, preparing visuals, and setting up promotion. Everything is moving forward.
**Done: **The event has successfully taken place. Now it’s time for follow-up, internal reporting, and repurposing any content generated.

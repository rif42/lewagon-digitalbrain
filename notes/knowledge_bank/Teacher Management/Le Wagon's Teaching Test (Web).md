# Le Wagon's Teaching Test (Web)
You want to become a teacher at Le Wagon, that's great! Complete this test first and send it to us. Good luck 💪​
## 1. Set up
The closer your own setup is to the [standard student's one](https://github.com/lewagon/setup), the better. That way you can share with them keyboard shortcuts. We use [VS Code](https://code.visualstudio.com/).
When you are running a lecture, please follow these guidelines:
- The only app running on your computer should be Finder, VS Code, Terminal and Browser
- Have your text editor and terminal with a **light background**. You can install the [Solarized](http://ethanschoonover.com/solarized) theme, and the [terminal theme](https://github.com/tomislav/osx-terminal.app-colors-solarized)
- Zoom a lot your font size (⌘=) in the text editor and your terminal.
- If you don't have a lot of files, hide the folder drawer on the left with ⌘K, ⌘B.
- Switch from one file to the other with the ⌘P (Command Palette)
- You should use two windows layouts:
        - VS Code in full screen
        - Vertical split (50/50) with VS Code on the right, Terminal on the left

### Recommendations
Some recommendations to help you prepare:
- Start by watching the video (you can put "accelerate mode") to understand the flow of the course, the examples and the live-codes used. You can take notes on a sheet of paper.
- Then go through the slides to see how you plan to alternate between slides and live-codes.
- Preparation should take you about one hour.
- Finally, just launch Quicktime, it's your turn!
Do not hesitate to contact us if you have any questions,
See you on the screencast!

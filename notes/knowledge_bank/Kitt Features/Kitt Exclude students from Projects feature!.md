# [Kitt] Exclude students from Projects feature!
We can now Exclude students from Projects directly in Kitt. This is a great way to manage students that are not following the code of conduct.
Example of use:
> “You are currently excluded from project weeks because you have breached the code of conduct/ Contract (Lateness, abscences, attitude…), but at Le Wagon we believe in second chances, so I will allow you to prove us wrong all the way up to project weeks, if you show us that you can follow the process and change your attitiude we will include you back into the projects.”

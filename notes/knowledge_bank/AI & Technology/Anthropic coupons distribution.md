# Anthropic coupons distribution
## Release note 🚀​
[[Redeem Claude Code Max coupons|🎁Redeem Claude Code Max coupons]]
Context :
With the new AI Software Development content, we’ve established a partnership with **Anthropic**. They provide us with coupons that allow our students to access **Claude Code**, which they’ll start using in **Week 8**.
At the beginning of each quarter, we need to inform Anthropic how many coupons we require (for both students and teachers). In return, they send us an Excel file containing a list of coupon codes.
Our goal is to distribute these codes to each student and teacher so that everyone can access Claude Code by Week 8.
👉 **Question:**
Would it be possible to automate the distribution of these coupon links to students through **Kitt**, using the Excel file provided by Anthropic?
Each coupon should be only used once, one per person.

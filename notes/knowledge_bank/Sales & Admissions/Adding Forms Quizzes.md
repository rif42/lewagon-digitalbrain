# Adding Forms Quizzes
1. Request an access on [forms.lewagon.com](http://forms.lewagon.com/) to use [[Draft Form for testing YAML without dbforms files|📄Draft Form for testing YAML without db/forms files]] and create the Quizzes YAML files
1. Request an access to [github.com/lewagon/forms](http://github.com/lewagon/forms) to submit the new YAML files via a Pull Request (e.g. [![](https://app.notion.com/images/external_integrations/github-pull-merged-icon.png)#503Add data crunching quiz for Roland Berger![](https://app.notion.com/images/external_integrations/github-pull-merged-icon.png)Merged](https://github.com/lewagon/forms/pull/503))
1. Request an access to [github.com/lewagon/assess](http://github.com/lewagon/assess) to submit the new “exam” via a Pull Request (e.g. [![](https://app.notion.com/images/external_integrations/github-pull-merged-icon.png)#607Update challenge names of Roland Berger quiz![](https://app.notion.com/images/external_integrations/github-pull-merged-icon.png)Merged](https://github.com/lewagon/assess/pull/607))
1. Ask an admin on [assess.lewagon.com](http://assess.lewagon.com/) to create the Assessments (one demo assessment for testing, and one for the actual assessment) and grant you **manager rights** on the sessions 👌​

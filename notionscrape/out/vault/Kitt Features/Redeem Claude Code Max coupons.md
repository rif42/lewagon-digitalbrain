# Redeem Claude Code Max coupons
## Context
In the context of the Le Wagon x Anthropic partnership, students and teachers of the AI Software Bootcamp may redeem 1 month of free Claude Code Max on the first day of Projects Weeks, after the AI-Assisted Coding lecture.
## Solution
**Students**
Students may redeem their coupons by navigating to <https://kitt.lewagon.com/redeem_claude_voucher> 👇​

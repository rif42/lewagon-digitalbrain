# How to add a new syllabus?
For now, creating a brand new syllabus requires quite a few steps to achieve:
First, create a new syllabus with a name / description, but make sure to leave the published_version empty as there is no version yet
![](https://app.notion.com/image/https%3A%2F%2Fprod-files-secure.s3.us-west-2.amazonaws.com%2F2b6dea13-478f-4f00-aff1-afd11ed5a03f%2F6e360d4d-8b08-4af6-a0af-e0fecd71edfb%2FScreenshot_2024-11-13_at_10.31.00.png?table=block&id=13d8924a-f014-8000-a6f3-e7ccdeedc9cd&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)
After creation you can then create a new version :
![](https://app.notion.com/image/https%3A%2F%2Fprod-files-secure.s3.us-west-2.amazonaws.com%2F2b6dea13-478f-4f00-aff1-afd11ed5a03f%2Fab9349f7-3afd-4bfa-a52c-4fdcecc13f95%2FScreenshot_2024-11-13_at_10.32.01.png?table=block&id=13d8924a-f014-80b1-bd8f-f43fb3ed9101&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)
You can fill in the major/minor version with 1 & 0 respectively, but then again leave the published tree blank, as it doesn’t currently exist:
![](https://app.notion.com/image/https%3A%2F%2Fprod-files-secure.s3.us-west-2.amazonaws.com%2F2b6dea13-478f-4f00-aff1-afd11ed5a03f%2F32860fc8-6595-4d76-ad3e-c0133812a899%2FScreenshot_2024-11-13_at_10.32.30.png?table=block&id=13d8924a-f014-801d-9c7a-e6e54bd11817&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)
Then you can click into the versions and create a new tree:
![](https://app.notion.com/image/https%3A%2F%2Fprod-files-secure.s3.us-west-2.amazonaws.com%2F2b6dea13-478f-4f00-aff1-afd11ed5a03f%2F58dbd952-f107-4f29-ae21-b685ba54a313%2FScreenshot_2024-11-13_at_10.33.19.png?table=block&id=13d8924a-f014-806e-a44c-eb8a7fde7d92&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=640&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)

And finally create a new syllabus tree with patch version 0 and any RFP description if you have one already:

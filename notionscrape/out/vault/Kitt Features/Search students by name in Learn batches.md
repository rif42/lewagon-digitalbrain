# Search students by name in Learn batches
### Context
Finding specific students in a Learn course to check their warm-up progress or prepwork completion is challenging when student lists are long. The current search functionality only allows instructors and administrators to search by **email address**, which slows down the process of monitoring student engagement and providing timely support. This limitation creates unnecessary delays in tracking student progress and intervening when students need assistance.
### Solution
**Search by first name, last name or email**
Instructors and administrators can now search for students directly by their first name, last name, or email address on the class students page. The search field accepts partial name matches, making it easy to locate students even when remembering only part of their name.

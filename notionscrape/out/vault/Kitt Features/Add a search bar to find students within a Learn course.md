# Add a search bar to find students within a Learn course
## Release Notes 🚀​
[[Search students by name in Learn batches|🔍Search students by name in Learn batches]]
## Summary
It is difficult and time-consuming to find a specific student in a Learn course to check whether they have started the warm-up or completed required prepwork.
- Some prepwork is not linked to Kitt (e.g. French prepwork).
        -
- Student lists can be long and hard to navigate.
        -
- There is currently no simple way to quickly find a specific student in a course.
        -
- Example page:
    <https://learn.lewagon.com/batches/3194/learners?selected=students>
**It would be helpful to add a search bar to easily find a student within a specific course.**

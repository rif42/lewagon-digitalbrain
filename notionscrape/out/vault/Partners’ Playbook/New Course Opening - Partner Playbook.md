# New Course Opening - Partner Playbook
*📋 This document outlines all the steps required to open your first batch of a new program in your city or region.*
## **Important Information**
All new program openings must be validated by the central team before launch. To get started, send your request to **@Sophie Parisot**, who will guide you through the validation process.
**Your request should include:** program name, delivery format, language, and pricing.
Your request is more likely to be approved if the following conditions are met:
- The program is fully up to date and live on Kitt/Learn
- The program has already been delivered at least once by HQ (no beta versions)
- The program is available in the language required by your city
- You plan to deliver in the same format as the central team
*⚠️ The central team provides resources in ****English and French only****. If you need content in another language (e.g. Spanish), prior approval from the central team is required. Your team will then be responsible for the translation, and all marketing workflow automations will need to be managed manually.*
---
## **Checklists**
### **⚖️ Legal (Contracts)**
- [ ] Get validation to launch your first batch: confirm program, format, and pricing [Legal team][Partner]
- [ ] If needed, sign a contract addendum with HQ to include the new program [Legal team][Partner]
### **💻 Engineering (Website display & application form)**
<!-- unhandled: header_4 -->
**Path A: Program page is on lewagon.com (WWW)**
*This applies to core bootcamps and skill courses.*
- [ ] Create your local course page using this guide from engineering: [[How to add a new program to your city|📔How to add a new program to your city]] [Partner]
- [ ] If your program does not show up on the homepage, navbar or anywhere else where it should, create [a Github Request to engineering](https://github.com/lewagon/help) to help and they’ll investigate on a case by case basis. Usually, it’s because they may be a guard clause that hides them for visitors on the homepage outside of a certain territory [Partner]
- [ ] Add the program to the "Next Sessions" page where it is currently hidden [Engineering team]
<!-- unhandled: header_4 -->
**Path B: Program page is on info.lewagon.com (Hubspot Landing Page)**
*This applies to all new products (AI Product Builder + AI & Data Automation)*
> *⚠️ ****One landing page (LP) per locale.****
> - A single LP serves all regions sharing a language (e.g. the French LP covers both France and Canada). Only the "Upcoming Sessions" section is dynamic and adapts based on visitor location.
> - You need to have the same content as the English Landing page just translated.*
- [ ] Check if the LP exists in your required language [Partner]
**The LP already exists in your language:**
- [ ] Create [a Github Request to engineering](https://github.com/lewagon/help) specifying the program you want to display in your Region. [Partner]
**The LP does NOT yet exists in your language:**
- [ ] Duplicate the existing LP and translate it [Partner].
- [ ] Create [a Github Request to engineering](https://github.com/lewagon/help) specifying the program you want to display in your Region. [Partner]
- [ ] Add the relevant regions to the visibility logic on the navbar and the homepage [Engineering team]
- [ ] Add the program to the "Next Sessions" page where it is currently hidden [Engineering team]
- [ ] Confirm sessions appear in the Upcoming Sessions module on Hubspot (ongoing request from Marketing) [Engineering team]
- [ ] Update the LP link in [Avo](https://www.lewagon.com/admin/resources/programs/20?force_locale=en) — a different URL can be configured per locale.[Engineering team]
### **📣 Marketing (Leads attribution, syllabus)**
> ***How it works:**** Leads are automatically attributed to your region based on the country of residence field collected in the syllabus form. Getting this right is critical — any change to the form structure can break tracking.*
<!-- unhandled: header_4 -->
**Path A: Syllabus (Standard Case) **
- [ ] Use the syllabus provided by the core team (available in French and English) available in [this drive](https://drive.google.com/drive/folders/1fEIo9MdSUNRKMbmIHC8Wlg86BlOS8Zfa) [Partner]
<!-- unhandled: header_4 -->
**Path B: Syllabus in another language needed **
*⚠️ If you plans to deliver the program in a language other than the original version, the following marketing rules apply : *
- [ ] Translate Syllabus materials. Send a message to @Pauline Florens to give you access.
- [ ] On your Landing Page, make sure to translate the Download syllabus module but DO NOT change any of the properties displayed (hidden or public) in the form. It could break tracking and lead attribution [Partner]
### **📚 Content (Program delivery & maintenance)**
- [ ] The program is fully up to date and live on Kitt/Learn [Content team]
- [ ] Client-specific customisation (if any) needs to be removed (e.g. sensitive B2B client data in a track) [Content team]
- [ ] All third-party tools used in the program are available in the Partner's region [Partner]
- [ ] The content is culturally appropriate for the Partner's market [Partner]
- [ ] The program has already been delivered at least once by HQ (no beta test) [Content team]
- [ ] The program is available in the language required by the Partner, or a translation has been formally approved [Content team]
*⚠️ If your Partner plans to deliver the program in a language other than the original version, the following content rules apply : *
- [ ] No translation may begin without prior written approval from the Content Team.
The Partner submits a translation request to the Content Team via <https://github.com/lewagon/help/issues> — using the **"Content - Partners & Partners"** template. [Partner]
- [ ] Upon approval, the Content Team provides access to the English source content. [Content team]
- [ ] The Partner organises and funds the translation locally, at their own cost following guidelines [Partner]
- [ ] The Content Team reserves the right to review translated content and request corrections before approving it for delivery. [Content team]
When HQ updates a program that a Partner has translated, the following process applies:
- [ ] The Content Team notifies the Partner's designated content contact via #**bootcamp-ops **on Slack, with a clear summary of what changed and which sections require updating. [Content team]
- [ ] The local team is responsible for translating the updated sections. [Partner]
### **⚙️ Operations (Batch creation, program delivery, onboarding)**
- [ ] Create a new batch on Kitt [Partner]
- [ ] If the batch needs to be available remotely in your region: open a GitHub ticket with your batch ID. We will make it Live Online [Partner]
- [ ] Read through the program operations playbook : [[Program playbooks & To Dos|📚Program playbooks & To Dos]] [Partner]
- [ ] Request an onboarding call with the central team to connect with a team that already runs the program [Partner] [Ops team]
- [ ] Recruit teachers [Partner]
- [ ] Run batch 🚀 [Partner]

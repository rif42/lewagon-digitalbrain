# Data Science - Python Prep Week 0
> [!note] 
> This document explains how to run pre-data science bootcamp** sessions of Python training**. This week is designed to help applicants in GO strengthen their Python skills before the Setup. Running this week is **mandatory** for all cities, it's part of the program. It can be *optional for some applicants* if they have a very strong Python level already.

# FAQ
### **What about part time?**
Part time Week 0 can be stretched over 2 weeks to fit the part time format (Tuesday / Thursday evening and saturday). In London here's the schedule we use:
- **Tuesday** (6.30 - 9.30pm) 👉 **Day 1 + challenges**
- **Thursday** (6.30 - 9.30pm) 👉** Day 1 + challenges**
- **Saturday** (10.00am - 5.00pm) 👉 **Day 2**
- **Tuesday **(6.30pm - 9.30pm) 👉** Day 3 + challenges**
- **Thursday** (6.30pm - 9.30pm) 👉 **Day 3 + challenges**
- **Saturday **(10.00am - 5.00pm) 👉 **Day 4**
- **Sunday** (10.00am - 5.00pm) 👉 **Day 5**
The last weekend is a 2-day sprint to cover everything left, then they have the week free and the setup is the following Saturday.
### **One of my applicants is an experienced developer, should they attend?**
Applicants who are developers are common but their main language is most likely not Python. Even someone comfortable with programming will benefit from this week and everyone should be encouraged to participate.
It also offers a chance for everyone to get to know each other before the bootcamp and familiarise with the bootcamp learning format.
### **Can we track progress of students during week 0?**
Learn has a dashboard with student completion, although the morning challenges are on Code Wars, which is not tracked on Learn. The challenges of the afternoon are hosted on Learn, but the tests are only checking that the students changed the code and ran it. We don't check if the code is correct.
### Students cannot play the video due to privacy settings
As reported in [https://github.com/lewagon/help/issues/1259](https://github.com/lewagon/help/issues/1259#issue-1555254273), browsers extensions can tamper with the HTML, resulting in a Vimeo Privacy error message. Disabling extensions, opening the page in an incognito window or using another browser usually solves it 👌​

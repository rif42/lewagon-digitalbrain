## **What will you learn during our Data Analytics bootcamp ? **
**Master data sourcing 💪**​
Understand the KPIs of companies, collect data from different sources to conduct the most emblematic analyses (churn, funnel, CAC, AB test, time to convert, cohorts...)
**Learn how to extract and transform data 🥽**​
Learn how to extract data via APIs, automation tools or tracking on Google Tag Manager. Master SQL and build structured data warehouses with software engineering techniques (ETL, DBT, versioning...)
**Business Intelligence and data visualization 📊**​
Communicate your results clearly by using the right visualisations and creating automated dashboards on millions of data with the most used BI tools.
**Python for analysis and prediction 🐍**​
Run analytics on large data sets with Python and Jupiter notebook. Understand the basics of Machine Learning in Python to collaborate with data scientists and take your analysis to the next level.

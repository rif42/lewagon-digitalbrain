# CHECKLIST: Post-production
- [ ] Trim raw footage (remove silences, shaky takes) 🎬
- [ ] Keep it short & punchy (under 2 min) ⏱️
- [ ] Apply smooth cuts (avoid heavy transitions) ✂️
- [ ] Add captions (check spelling & timing) 📝
- [ ] Add branding (colors, logo, fonts) 🎨
- [ ] Add background music (low volume, copyright-free) 🎶
- [ ] Insert B-roll if needed (stock or recorded) 🌆
- [ ] Export in correct ratio (9:16 vertical for socials)📱
- [ ] Final check on mobile (sound, light, captions) 👀
- [ ] Upload & publish (share link in Notion/Slack) 🚀

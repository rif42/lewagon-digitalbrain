# Additional recs
- Use brand colors and available assets - [![](https://static.lingoapp.com/web/assets/favicons/apple-touch-icon-1024x1024.png)LingoLingo — The visual home for your brand](https://www.lingoapp.com/90421/k/Brand-Assets-P7j8m1)​
        - FYI, although red is our brand color but we don’t use it as much in our emails
- Do not mix native hubspot editor with templates, only use on or the other
- If you feel there is a design option missing, you found an issue, or simply want to share a template idea - add them all her and we can ask our freelance to create it - [No access](https://app.notion.com/p/8472f74cc7ae46729758a37b511ae0e7?pvs=24#8472f74cc7ae46729758a37b511ae0e7)
- The goal is to use templates, but if you need to create something very specific:
        - Use native hubspot editor for full email and adapt the design to our branding by using HTML
                    - 40px margins
                    - 16px Inter Regular font
                    - Circular font for titles/headers
                    - 1.5 spacing

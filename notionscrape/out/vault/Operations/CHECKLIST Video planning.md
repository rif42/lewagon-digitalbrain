# CHECKLIST: Video planning
- [ ] Define goal & audience 🎯​
- [ ] Find inspiration (save examples) 💡​
- [ ] Draft script or prompts ✍️
- [ ] Confirm subject(s) & get consent 👥​
- [ ] Pick location (check light, sound, background) 📍​
- [ ] Prepare equipment (phone tripod, mic if available) 🎥
- [ ] Plan shots (storyboard or rough outline) 📝
- [ ] Do test shot (check framing, audio, light) 🎬
- [ ] Add branding (text overlays, logos, colors) 🎨​
- [ ] Export in correct format (vertical for social, horizontal if needed) 📱​
- [ ] Share for review → publish 🚀

# Embedded Apply Forms w/ tags
## Context
At the minute, it is not possible to configure a www embedded apply form on multiple cities and or programs. The two supported options forces to choose between
- Option 1: one or all programs, in one or all cities
- Option 2: a fixed list of batches, limited due to performance issues
## Solution
To offer more flexibility, we are introducing a third option which consists in (i) setting up one or several tags on Kitt batches 👇​

# Sending Grouped Emails + Prep-Work Nagging Templates
> [!note] 
> The page below covers how to send email and prep-work reminders on KITT; and a few copy-paste templates to get the nagging job started 🚀
This page is intended for the program management team (City, Program or Batch Managers)
## 0. Sending Automatic Reminder Emails on KITT ✉️​
---
This feature allows you to send a first reminder that is automatically set on the ATS. This is only possible for the program management team that has access to the ATS.

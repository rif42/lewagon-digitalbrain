# CHECKLIST: Video production
- [ ] Phone ready (storage + battery + airplane mode) 📱​
- [ ] Correct settings (1080p or 4K, 30fps or 60fps) ⚙️
- [ ] Test sound (quiet environment or external mic) 🎙️
- [ ] Test light (face subject towards natural light or ring light) 💡
- [ ] Frame properly (eye-level, good headroom, uncluttered background) 🎬
- [ ] Record multiple takes (at least 2–3 per scene) 🎥
- [ ] Capture B-roll (to cut between shots) 🌆
- [ ] Quick playback check (sound, framing, light all okay) 🔎
- [ ] Add overlays/branding in editing 🎨
- [ ] Export in correct format (vertical/horizontal) 🚀

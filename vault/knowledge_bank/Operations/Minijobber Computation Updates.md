# Minijobber Computation Updates
## Context
The MiniJob hiring system is the core for working with teachers in Germany.
The current implementation on Kitt is working very well, however there is some information and flexibility missing which would help the team to manage the contracts more efficiently. This is related to the midi and mini contract types and teachers’ financials.
## Solution
We have added the possibility for the German team to be able to change a contract type from mini to midi and vice versa if certain conditions are met.
We also now display more detailed financial insights about the Minijobber contrat.

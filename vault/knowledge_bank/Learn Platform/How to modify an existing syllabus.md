# How to modify an existing syllabus?
### Creating a draft
To create a new draft from the latest version of a syllabus, you can choose to edit from the top right corner:

### Search forms
Choosing to add something new will provide a search form for that type (module vs unit vs block). Once you’ve found what you want, you can import it to the current syllabus:
![](https://app.notion.com/image/https%3A%2F%2Fprod-files-secure.s3.us-west-2.amazonaws.com%2F2b6dea13-478f-4f00-aff1-afd11ed5a03f%2F92e651ef-2457-46f6-92d2-751eb05e2b60%2FScreenshot_2024-11-13_at_12.27.52.png?table=block&id=13d8924a-f014-807f-a299-e510c915e013&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)

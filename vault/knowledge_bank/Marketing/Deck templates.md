# Deck templates
> [!note] 
> Find here our presentations for info sessions, talks, workshops, and generic pitches.
### How to correctly use these templates
1. Never edit the master slides ❌​
1. Open the deck that you’d like to use
1. You only have a view permission, therefore please follow
    → File / Make a copy / Entire presentation
1. Name the copied file and save it wherever you want
1. Open the new file → Now you will have editor permission
1. You’re good to go! 🎉​

### How to correctly use the Google Slides Template
1. Never edit the master slide ❌​
1. Open the the master template slides → [here](https://docs.google.com/presentation/d/1EtAcGbncaG3o7icz9-tSDMmyw7Is0M8hp-HL-dNiB_Y/edit#slide=id.g11c88abe72c_0_40)
1. You only have a view permission, there please follow
    → File / Make a copy / Entire presentation
1. Name the copied file and save it wherever you want
1. Open the new file → Now you will have editor permission
1. Add a slide like this ⬇️
    ![](https://app.notion.com/image/https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2Fabd912d9-9668-44ad-8e23-456e17832b8b%2FUntitled.png?table=block&id=f9941ca1-6fff-409f-abe1-05f1cd6187bf&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=450&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)
1. Mix it up and enjoy! 🎉​

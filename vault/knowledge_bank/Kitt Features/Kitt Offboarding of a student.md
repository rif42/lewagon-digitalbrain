# [Kitt] Offboarding of a student
You can now Completely Offboard a student from Kitt, before completely offboarding a student from a batch, make sure to check if removing from projects/Buddy system is a better intermediary measure to take ([[Kitt Exclude students from Projects feature!|see Excluding a student from projects]])
### **How to move Offboard a student
**
Go to this link : [https://kitt.lewagon.com/camps/{slug}/flags](https://kitt.lewagon.com/camps/2150/flags)
- Add a new flag
- Select the type of flag
- Save
Go on the line once the flag was created
![](https://app.notion.com/image/attachment%3A0adbf62d-df7b-446a-9649-0cdcd90531a3%3A1e55646f-0239-4941-a84a-11c49794b784.png?table=block&id=29b8924a-f014-8049-8b81-f54dd633cebe&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)
- Select the option you want : Exclude / Batch 0 / Offboard
        - ***Exclude from buddies/projects ***: Temporarily removes the student from the Buddies and Projects features. You can change this setting later and **re-include **the student at any time.
        - ***Batch 0*** : The student retains access to the learning content and can continue studying **at their own pace**.
        - ***Offboard*** : Revokes **all access **for the student (e.g., in cases such as payment issues or other exceptional situations).
        ⚠️ **Important: **When offboarding a student, make sure to **record the student’s final revenue in cents. **

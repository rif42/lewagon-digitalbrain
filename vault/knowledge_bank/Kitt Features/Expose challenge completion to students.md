# Expose challenge completion to students
## Context
In several cities, reaching a minimum completion percentage has become a funding requirement. Currently, only internal **staff have access exercise completion rate via the Kitt camp dashboard**.
![](https://app.notion.com/image/attachment%3A0e17e5b5-c1fe-45fd-90da-be18c79f3ff0%3ACleanShot_2025-05-21_at_14.41.382x.png?table=block&id=1fa8924a-f014-80a4-a996-d2398850663a&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)
**Students lack visibility** into their own progress and must **frequently ask for updates**. However, this approach creates a significant manual workload for the team.
## Solution
**Student dashboard without completion rate**
By default, the completion rate is not displayed on the student dashboard.
![](https://app.notion.com/image/attachment%3Ab347f7e6-5def-40c7-af9b-7734aca317bd%3Aimage.png?table=block&id=1f98924a-f014-80e5-85d8-c9a5c6bb14b2&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)
**Completion rate display activation**
The completion rate display on the student dashboard can be **activated at the batch level via the batch settings or active_admin****.**
![](https://app.notion.com/image/attachment%3Af5c5bbae-7a22-41f7-8fe6-59daedfc20dc%3ACapture_decran_2025-05-21_a_09.48.27.png?table=block&id=1fa8924a-f014-8074-b13e-f8685fa0c6c3&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)
![](https://app.notion.com/image/attachment%3Ac28f5be2-f747-4ec8-8b3e-c492a46643ab%3ACapture_decran_2025-05-20_a_12.13.21.png?table=block&id=1f98924a-f014-80b4-b7b3-fd601588323b&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)
The completion rate can be also be activated at the student level.
![](https://app.notion.com/image/attachment%3A32144967-bc33-4fdf-836c-bed9d2af7e07%3ACapture_decran_2025-05-20_a_06.48.40.png?table=block&id=1f98924a-f014-800c-a3b2-d69401dcc35a&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)
**Student dashboard with the completion rate**
For full time batches, students will see their completion rate next to “Bootcamp” Activity. Hovering the completion rate will display a tooltip giving explanation on how this completion rate is computed.
![](https://app.notion.com/image/attachment%3Ac312dbde-77fc-4ddf-a139-6d019be25015%3ACapture_decran_2025-05-20_a_10.29.17.png?table=block&id=1f98924a-f014-80f0-a35a-d2fab17d23f2&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)
For Part-Time batches, a new component “Completion Rate” has been added. Hovering the completion rate will also display a tooltip giving explanation on how this completion rate is computed.
![](https://app.notion.com/image/attachment%3A7a38cc86-fe82-46b0-bc5f-1659c3048737%3ACapture_decran_2025-05-20_a_15.28.22.png?table=block&id=1f98924a-f014-8064-ad63-deb1f9a4dd5a&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)

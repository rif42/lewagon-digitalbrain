# Extend student flags display
## Context
Some Le Wagon applicants have previously taken other courses and/or have submitted multiple applications. Thanks to the new [[At-risk Student Tracking|Flagging feature]], we can track applicants so that if they become students, batch managers and career counsellors are able to look into their history over time, as early as the application stage. However, it’s not currently possible to see flag history from across multiple and/or past applications.
## Solution
We have moved the Multiple Applies section to the top of the page and added the flags directly on each multiple apply. This way, Admissions can easily see which other flags have appeared on relative applications.

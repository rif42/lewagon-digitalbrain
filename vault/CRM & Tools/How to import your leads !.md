# How to import your leads !
> [!note] 
> **You cannot import "cold contact" coming from the bought list.** Hubspot is not an outbound CRM. You need to qualify them at a minimum with another tool.
**Hubspot is an inbound CRM.
AND
You can import only leads who accepted to opt-in to our newsletter**
**Step 1 | Prepare your file
**
First-able, you have to prepare your file. To help you and save time, please to clone [this spreadsheet](https://docs.google.com/spreadsheets/d/1aPytvSGV3sYA4nwILg-CDXHnVUo5CNk8oCDlLdGUERY/edit?usp=sharing) (V2), **rename it **and **copy paste your values in the right columns.**
**In the row 2, for some properties, you will find a dropdown with right values to use.
⚠️⚠️⚠️ F****OR EVENTS, DO NOT FORGET TO ADD THE EVENT ID FROM AVO ****⚠️⚠️⚠️**
**After filled columns, do not forget to delete the row 2&3 and make sur that all columns with date respect this format: MM/DD/YYYY.**
Once done, go to File > Download > Comma Separated Values (.csv)

**Step 7: Map your columns**
All should be automatically mapping. But, please check if all mapping are well.
Before clicking on Next, make sure to **check ✅ the box “Don’t import data in unmapped columns”
**** ****🙂 If you filled correctly every column, all is automatically mapping 🙂****
****⚠️ Check the box “don’t overwrite” for the property called “ First touch”
⚠️ If you have “First Touch” or “Touchpoints” to import always import them as “Touchpoints” in Hubspot**
![](https://app.notion.com/image/https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2Fd5f5aa14-0952-4c37-9573-6970f634fc96%2FScreenshot_2023-07-03_at_10.32.49.png?table=block&id=1858924a-f014-8197-88b5-fcca87e199d1&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)
---
**Step 8: Rename your import
**Last step, take time to rename your import. Then, if you want, you can check the box “Create a list from this import”. You will find it easly in the list section by using the name of your import.
For “Select the legal basis for processing a contacts data”, **select “Legitimate interest - prospect/lead”**
No need to change the date format.
Last action, click on **“Finish import”. **
Congrats ! 🎉 Your import your list in Hubspot !

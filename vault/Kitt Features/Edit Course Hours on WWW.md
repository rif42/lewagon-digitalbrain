# Edit Course Hours on WWW
## Context
The current course cards on our website show the default hours defined for courses, whether it’s full-time or part-time. The way we currently handle this is not flexible and city staff is unable to change these hours easily, which can be a hassle since the session start and end hours are potentially prone to change.
## Solution
You can now edit the hours yourself directly from the WWW admin 🙌​
Just head over to [this link](https://www.lewagon.com/v4/admin/resources/course_formats) and you will be able to change the start and end times of courses.
![](https://app.notion.com/image/https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2F16a0d09b-de95-46f8-832a-7456410ce458%2F199766945-213f6899-0bb1-4052-bd96-44ea6a56168d.png?table=block&id=59aae0b1-f165-406a-863c-cbd06f965fb9&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)
For part-time batches, you can edit the hours of both weekday sessions and weekend sessions.
![](https://app.notion.com/image/https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2F0a04e282-7867-485e-bbce-57c6ebabdf4c%2F199766979-c536725b-24db-4740-a5d9-8057d5579f30.png?table=block&id=71b51be3-25b1-4cbc-abb9-43b0571432f2&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)

# Certification Session XML Export
> [!note] 
> This feature is meant to be used in 🇫🇷 only in the context of the Mon Compte Formation funding.
## Context
In order to get paid by funding organisms who take on a student’s tuition, we must provide some official documents in exchange.
An example of this is the French “Mon Compte Formation”, which needs to make sure that the student getting the funding successfully passed our certification session that we put in place for France.
## Solution
To prove this, Mon Compte Formation asks for an XML file which has all the required information about the candidate, Le Wagon and the certification session. They provided us a clear template and we’ve updatedo our Assess platform to be able to generate such a file.
When the results of the session in question have been published, you can now Export to XML which will trigger the download of the file 👇​

# How to create an exam session?
To create a new exam session, go on Assess root page and click on Create a new session or follow [this link](https://assess.lewagon.com/exam_sessions/new).
![](https://app.notion.com/image/https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2Fa87afdc1-5737-4ab4-8ae3-7c51c7bf79d4%2FScreenshot_2022-01-24_at_14.55.15.png?table=block&id=6c429e21-8cf0-4ec1-b08f-9dc520ba4c17&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)
You will land on a page listing all the exams available on the platform.
![](https://app.notion.com/image/https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2F7df01ee3-a380-481d-9e94-c29dd773b0af%2FScreenshot_2022-01-24_at_14.57.57.png?table=block&id=abd803fb-1e70-4c53-a973-1b049d1367ac&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)
> [!note] 
> For RNCP exam sessions, all the skills of the Web or Data exam must be checked.
# 1. Choose competencies to assess
By clicking on an exam name, you access to all the competencies assessable, grouped by blocks.
![](https://file.notion.com/f/f/2b6dea13-478f-4f00-aff1-afd11ed5a03f/89e7f263-b0cb-4d53-9522-6c00e0ef821d/Kapture_2022-01-24_at_15.10.48.gif?table=block&id=82bf0ef3-9ae6-4010-bd4f-dd542eef7f6b&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&expirationTimestamp=1784851200000&signature=Wa7_n181zzXeWZeN90joYtvshqV9Cg_NeCeUZSmhZ9E)
Select all the competencies you want to assess during the exam session, and for each competency select a challenge in the right dropdown.
![](https://file.notion.com/f/f/2b6dea13-478f-4f00-aff1-afd11ed5a03f/77558ae1-2a51-410e-9ea8-6730efc19024/Kapture_2022-01-24_at_15.16.06.gif?table=block&id=a0cd9dff-76d0-424d-9662-666940694443&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&expirationTimestamp=1784851200000&signature=ICxbgEBvPqOdLtQySKC8nwEmRSWpcF2dxK_PjBPiUXs)
> [!note] 
> For now, you cannot select competencies from different exams in the same session.
When all the competencies you want to assess are selected and have a challenge associated, click on the Next button to go to the exam session setting panel.
# 2. Session settings
## a. Name and challenges sequence
Type the name you want to give to the session and hit the Enter key on your keyboard.
![](https://app.notion.com/image/https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2F8546d82a-bb94-47e2-83e1-b80edeca0b41%2FScreenshot_2022-01-24_at_15.22.12.png?table=block&id=05d253bd-8579-44c0-832d-38486ef8e1fd&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)
Then, precise if your session is Sequential or Non-Sequential. It will reveal the session global settings panel.
![](https://file.notion.com/f/f/2b6dea13-478f-4f00-aff1-afd11ed5a03f/74c6ad89-b2a7-4d12-86bb-25005315dc37/Kapture_2022-01-24_at_15.24.28.gif?table=block&id=2410fdd2-e1e7-4172-9b43-820b087d63ea&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&expirationTimestamp=1784851200000&signature=oSnxAaME8uD-gfRhSPHEKDsNnms9PGUhvBrGritvt7E)
> [!note] 
> **Should I create a ****Sequential**** or a ****Non-sequential**** exam?**
If you are running a RCNP certification exam choose the **Sequential**** **option** **👍​
## b. Global settings
### Time zone and dates
First select the time zone, the starting date and the ending date of your exam session.
![](https://app.notion.com/image/https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2Fb8451314-a894-4c20-ac63-eae6be6d9275%2FScreenshot_2022-01-24_at_15.59.42.png?table=block&id=a3ffd730-0457-4a04-b3c2-9c5e0d7faadb&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)
> [!note] 
> Choosing the right timezone is really important. It’s based on this time zone that dates will be displayed in the interface and on the generated documents.
### Data runner
If you’re running a data exam, you will also see a field to select the Data runner tag.
![](https://app.notion.com/image/https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2Ff5a9d304-db9b-447b-9e51-2ec3dc682f0c%2FScreenshot_2022-01-27_at_18.20.59.png?table=block&id=4ee0dbe5-e6fe-4984-bc80-4d38d23ed14c&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1380&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)
> [!note] 
> For RNCP exam, let the default selected value.
### Kitt sign in
> [!note] 
> Mandatory for RNCP exam sessions.
You can allow candidates to sign in with Kitt or not, depending of the session you want to run.
It’s **highly recommended to activate it for RCNP exam sessions** (as most of the candidates are former Le Wagon students) whereas it’s not mandatory for a B2B exam session.
![](https://app.notion.com/image/https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2Fde28aced-b1d5-43ec-8146-140fc567b1dd%2FScreenshot_2022-01-24_at_16.04.41.png?table=block&id=5c0f1804-5edc-4176-b4db-84a6c82cb832&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)

### Group skill per blocks
> [!note] 
> Mandatory for RNCP exam sessions.
You can choose to group skills per blocks for the assessment step.
It’s handy if you want to assess block of competencies (like in RNCP exam) and it will also let you set a block validation threshold to help jurors in their rating.
![](https://app.notion.com/image/https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2F5064ec16-88d0-46b9-a86f-1aa141aca2cf%2FScreenshot_2022-01-24_at_16.05.10.png?table=block&id=a589991b-81dc-4020-a50b-f056b512e874&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)
> [!note] 
> For RNCP exam session, set the threshold to 50%.
### Import candidates previous attempts
> [!note] 
> Mandatory for RNCP exam sessions.
If you check this option, Assess will gather candidates previous attempt and will automatically import blocks validated during previous sessions.
![](https://app.notion.com/image/https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2F62f00f40-4155-4461-8b86-427c9627e3b0%2FScreenshot_2022-01-24_at_16.05.24.png?table=block&id=92a97114-1a9e-4f8e-93d1-6f5479998548&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)
### This exam is organized by Le Wagon Paris
> [!note] 
> Check this box only if you are creating an exam session for Le Wagon Paris.
This information is mandatory to generate XML exports for the [[Certification Session XML Export|french organism Mon Compte Formation]].
### Description
You can set a short description of your exam session in order to give context to candidates during their onboarding.
![](https://app.notion.com/image/https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2F16952e04-9b84-4afa-87e6-111ec0b2a92a%2FScreenshot_2022-01-24_at_16.32.55.png?table=block&id=2bbcd57d-abdd-4842-9bce-d108abc4aadd&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)

## c. Documents settings
### Documents default language
You can choose between the default language of the document between English and French.
> [!note] 
> Choose French for RNCP exam session.
### Convocation
> [!note] 
> Mandatory for RNCP exam sessions.
You can choose to automatically send a convocation document to candidates as soon as they are accepted.
This setting is mandatory if you are running a RNCP exam.
![](https://app.notion.com/image/https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2Fd53d6415-8ee6-4c3f-adad-2bb9503939bf%2FScreenshot_2022-01-24_at_16.33.56.png?table=block&id=fd3c9737-7cb9-456c-b9ce-3614d3d0da61&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)
> [!note] 
> For now, Assess has only one convocation template available (the RNCP one).
Please contact the Engineering team if you need to add another template.
### Certification
> [!note] 
> Mandatory for RNCP exam sessions.
Checking this option will allow you to generate 2 documents for each candidate:
- A certification (for candidates who have been certified by jurors)
- A validated block document (for all candidates)
If you want to generate only one of this document, just choose the blank option in the template dropdown.
![](https://app.notion.com/image/https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2Fcb2bbc40-1801-416a-ace3-166210c72d09%2FScreenshot_2022-01-24_at_16.34.26.png?table=block&id=9a62a89b-9b7b-45ad-929d-b8448a2cddd4&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)
> [!note] 
> Here you can also choose default email templates if you want to be able to send generated documents by email to candidates.

## d. Jurors settings
### Certificate of experience
> [!note] 
> Mandatory for RNCP exam sessions.
If needed, you can choose a certificate of experience that each juror will need to sign in order to justify their experience in a field of competency.
This is a mandatory option for RNCP exam session.
![](https://app.notion.com/image/https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2F0da365f5-694c-4cb7-8c46-2e12861402eb%2FScreenshot_2022-01-24_at_17.02.12.png?table=block&id=ac3d63aa-4bb1-479b-b41d-174b105ec8d3&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)
### Juries
> [!note] 
> Mandatory for RNCP exam sessions.
If you want candidates to be assessed by several jurors, select this option.
This will also add an extra step of deliberations during the assessment process. During the deliberation, all the jurors from a jury will have a live meeting in order to deliver or not the certification to candidates.
This is mandatory for RNCP exam session.
![](https://app.notion.com/image/https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2Fbe82a71a-eaca-48a2-8ded-3abe2ac89902%2FScreenshot_2022-08-31_at_1.55.25_PM.png?table=block&id=09c6a7cb-0d6e-4638-b0ea-e3c7a973c1b4&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)
> [!note] 
> For RCNP exams, you will also need to choose a minutes template.
Minutes is a document signed by all the jurors from a same jury, which gives an overview of candidates results.
When all the fields are properly set, click on the Create button on the bottom of the page. It will redirect you to the challenges settings.
# 3. Adjust challenges settings
By default, exam session's challenges will be created with default settings that you’re allowed to edit.
![](https://app.notion.com/image/https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2Fd2cd5287-012b-4c2a-98de-658f7c3478b7%2FScreenshot_2022-04-04_at_17.10.03.png?table=block&id=99f638ec-2dfb-474c-ace0-afded59177aa&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)
You can update the **starting date** and the **duration** of each challenge.
> [!note] 
> This will only impact the schedules displayed on the convocation document.
If you aren’t using a convocation document for your session, don’t change the default settings.
# 4. Create the exam session
When all the fields are properly set, click on the Validate challenges settings button on the bottom of the page. It will redirect you to the exam session dashboard.
![](https://app.notion.com/image/https%3A%2F%2Fs3-us-west-2.amazonaws.com%2Fsecure.notion-static.com%2Fa3bd261f-0bc0-411f-944e-577a6923c501%2FScreenshot_2022-01-24_at_17.19.53.png?table=block&id=87cad28a-e863-4b6a-bc19-af262f419f22&spaceId=2b6dea13-478f-4f00-aff1-afd11ed5a03f&width=1410&userId=342d872b-594c-817d-8145-000204a2c537&cache=v2&imgBuildSrc=requestProxiedImageUrl)

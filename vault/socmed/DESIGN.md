# Le Wagon Bali Social Media Design System

Absolute source of truth: [[Le_Wagon-Branding_Guidelines-Feb2024.pdf|Le Wagon Brand Guidelines — Feb 2024]] and [[Le Wagon Bali Content Guide]]. This design system is a ready-to-use spec for Le Wagon Bali social media assets.

## 1. Brand Identity

- The logo and minibus symbol represent a collective learning journey: immersion, transformation, and collaboration.
- Use only the updated squared logo and three-window minibus symbol.
- Never use the old circular logo, old four-window minibus, or old red `#FD1015`.

## 2. Logo Usage

### Variants
- **Combination mark:** wordmark + minibus symbol.
- **Symbol:** minibus only.

### Safe zone / exclusion
- Combination mark: clear space on all sides equal to the symbol height.
- Symbol alone: clear space on all sides equal to half the symbol height.
- Co-branding: leave a gap equal to the symbol width between the Le Wagon logo and any partner logo.

### Minimum sizes
- Combination mark: 30px minimum height; standard 90px.
- Symbol: 30px minimum height; standard 90px.

### Colour on backgrounds
- Logo wordmark should be white over photos.
- Place the logo in a neutral area of the image; add a 20–30% black overlay if needed.
- Never use the logo or symbol on a red background.
- Maintain adequate colour contrast.

### Logo don'ts
- Do not modify, stretch, distort, or rotate the logo.
- Do not change logo colours.
- Do not add effects (drop shadows, bevels, glows).
- Do not replace the wordmark typeface.
- Do not use outdated versions.

### Secondary colours

### Background colours
| Name        | Hex       | Usage                                               |

### Gradients
- For social and paid ads only.
- Use the predefined gradient palette: Dark Purple `#371373`, Gradient Light Purple `#5211BC`, Purple 05 `#F5F2FB`, Purple 20 `#DBCDF3`, Cream `#FCF3EE`.

### Accent colours
| Name           | Hex       | Usage                        |
| -------------- | --------- | ---------------------------- |
| Orange Peel    | `#FF9D0B` | Pill accent label text       |
| Orange Peel 20 | `#FFECD0` | Pill accent label background |

### Colour rules
- Never use red or black as background colours.
- Never use Blue Purple `#4D04C4` as a background; use Purple `#5315B8` instead.
- Never use Le Wagon Red as a font colour.
- Never use red or orange as a highlight colour.
- Never use undocumented or alternative colours.
- Avoid mixing too many purple variants in one asset.
- Ensure sufficient contrast, especially for text.

## 4. Typography

### Typefaces
- **Circular:** headings only. Weights: Bold 700, Medium 500.
- **Inter:** body copy, labels, buttons. Weights: Bold 700, Regular 400.

### Rules
- Do not use Inter for headings or Circular for body copy.
- Do not use italics.
- Use the approved weights only.

### Web hierarchy
- Labels: Inter Bold, uppercase.
- Headings: Circular Medium, line-height 1.1 / 110%, letter-spacing 0.
- Buttons: Inter Bold, uppercase.
- Paragraphs: Inter Regular, line-height 1.5 / 150%.

### Social / ad hierarchy
- Heading: Inter Bold, line-height 1.1–1.3 / 110–130%.
- Rating: Inter Bold.
- Button: Inter Bold.
- Key figure: Inter Bold.
- Label: Inter Medium, uppercase.
- Subtitle: Inter Medium, line-height 1.2 / 120%.

### Type colour
- Do not layer bright colours on bright colours or dark on dark.
- Do not use red as a font colour.

## 5. Imagery & Graphic Language

### Photography
- Use real Le Wagon students, teachers, drivers, and alumni from the internal image bank.
- Warm, positive, diverse — show people and energy, not stock models.
- Represent the life change and pleasure of learning.

### Corner radius
- Images: 16–24px.
- CTAs: 8px.
- UI cards: 24px.
- Labels may be more rounded than other elements; do not over-round corners for non-label elements.

### Effects
- No borders, strokes, or drop shadows on images.
- No drop shadows on graphic elements.
- The only allowed shadow is for the predefined social CTA: `0px 4px 28px 0px rgba(0, 0, 0, 0.05)`.

### Symbols and icons
- Use the brand icon library from the Figma guidelines file.
- No emojis except in Demo Day visuals.

### Highlighted text
- Use brighter colours than the surrounding text, usually purple or light purple.
- Do not highlight more than two words at a time.
- Do not use red or orange as a highlight colour.

## 6. Layout Specs

### Social media formats
| Format | Dimensions | Margins | Platforms |
|---|---|---|---|
| Paid ads | 1080×1080px (1:1) | 60px | Instagram / Facebook / LinkedIn |
| Organic posts | 1080×1350px (4:5) | 60px | Instagram / Facebook / LinkedIn |
| Stories | 1080×1920px (9:16) | Top & Bottom 250px, Left & Right 60px | Instagram / Facebook |
| Eventbrite / Meetup | 1186×666px (16:9) | 72px | — |

### Backgrounds for social
- Default social/ad background: Purple `#5315B8`.
- Alternatives: Dark Purple, Purple 05, Cream, White.

## 7. Components

### Logo
- White wordmark over imagery, placed in neutral space.
- Minimum 30px height; 90px standard.

### Primary CTA
- Font: Inter Bold.
- Colour: Tonic Purple `#670BFF`; or Le Wagon Red `#E60F05` on Dark Purple.
- Corner radius: 8px.

### Secondary CTA
- Font: Inter Bold.
- Colour: White `#FFFFFF` with Tonic Purple `#670BFF` stroke.
- Corner radius: 8px.

### Highlight label
- Brighter text on sentence background; usually purple or light purple.
- Limit to two words.

### Pill accent label
- Text: Orange Peel `#FF9D0B`.
- Background: Orange Peel 20 `#FFECD0`.

### Info card / star rating
- Uses the predefined social CTA shadow: `0px 4px 28px 0px rgba(0, 0, 0, 0.05)`.
- Font: Inter Bold for labels.

### List item icons
- Use the brand icon library.

## 8. Brand Guardrails

- Only use the updated squared logo and three-window minibus.
- Never use red or black backgrounds.
- Never use Blue Purple as a background.
- Never use Le Wagon Red as a font colour.
- Never use red or orange for highlights.
- Never add strokes, borders, or drop shadows to images.
- Never use alternative fonts or colours.
- Never use emojis except in Demo Day assets.
- Never use gradients outside predefined social/paid-ad templates.
- Never use more than two highlighted words.
- Avoid too many purple variants in one asset.

## 9. Audience & Content Guardrails

- All assets target the 25–40 mid-career professional, sweet spot 28–33.
- Rotate between Career Pivoter, Remote Upskiller, and Builder / Freelancer motivations.
- Every post must pass the four content filters in [[Le Wagon Bali Content Guide]].
- Voice: direct, confident, practical, lifestyle-aspirational but not tourist-y, community-focused, evidence-based.
